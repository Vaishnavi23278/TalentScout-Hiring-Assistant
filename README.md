# TalentScout Hiring Assistant

## 📌 Project Overview
This project is an AI-powered Hiring Assistant chatbot built using Streamlit and Large Language Models (LLMs). It collects candidate details through an interactive chat interface and generates technical interview questions based on the candidate's declared tech stack and experience level.

---

## 🚀 Features
- Interactive chatbot interface using Streamlit  
- Collects candidate details (name, email, phone, experience, role, location, tech stack)  
- Input validation (email, phone, experience)  
- Handles irrelevant inputs gracefully  
- Generates 3–5 technical interview questions using LLM  
- Questions are tailored to the candidate’s tech stack  
- Clean and professional output formatting  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- Groq API (LLM - LLaMA 3)  
- Requests
